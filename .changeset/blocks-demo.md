The guide's Blocks section ports four of shadcn's blocks, each a tested page in a frame of its
own: `login-01`, `signup-01`, `dashboard-01` (an inset Sidebar, section cards, an interactive
area chart, and a data table whose rows drag into a new order, by mouse, touch or keyboard),
and `sidebar-13`, the settings dialog. The live demo, `test-app` built into `docs/site/demo`, is
the dashboard, with the settings dialog over it at `/settings`. Blocks aren't exported from a
package, so no package changes.
