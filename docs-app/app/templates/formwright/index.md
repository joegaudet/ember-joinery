# Formwright

shadcn's `Form` is built on react-hook-form. Joinery's is
[Formwright](https://joegaudet.com/ember-formwright/), through `@ember-joinery/formwright`:
every Joinery input as a Formwright control, a field layout with shadcn's Field anatomy, and
harnesses built on Formwright's own.
