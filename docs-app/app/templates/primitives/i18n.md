# I18n

Every string a Joinery component shows itself is a `Message`, shown through the app's
translator, or in English without one. `@ember-joinery/primitives/i18n` is how: use it in
components of your own for the same. [Internationalization](/getting-started/i18n.md) covers
registering a translator.

<Example @name="i18n-translator" @title="A slider's thumbs, named by the app's translator (see the Test tab)." />

## Usage

```gts
import Component from '@glimmer/component'
import { t, translate, type Message } from '@ember-joinery/primitives/i18n'

const close: Message = { id: 'app.panel.close', message: 'Close' }

export default class Panel extends Component<{ Args: { closeLabel?: string } }> {
  get closeLabel(): string {
    return this.args.closeLabel ?? translate(this, close)
  }

  <template>
    <button type="button" aria-label={{this.closeLabel}}>×</button>
    <span>{{t close}}</span>
  </template>
}
```

Each package's own messages are data, at `<package>/messages`
(`@ember-joinery/primitives/messages`, `@ember-joinery/ember/messages`), for a translation
catalog.

## API

| Export                                 | What it is                                                                                          |
| -------------------------------------- | --------------------------------------------------------------------------------------------------- |
| `Message`                              | `{ id, message, plural?, context?, description? }`: a string, its English and `{name}` placeholders |
| `Translator`                           | `{ locale, t(message, values?) }`, registered as `translator:main`                                  |
| `format(message, values?)`             | The English: `plural` when `values.count` isn't one, each `{name}` filled in                        |
| `translate(context, message, values?)` | The context's app's translator's string, or `format()`'s without one                                |
| `t`                                    | `translate` for a template: `{{t message (hash name=…)}}`                                           |
| `translator(context)`                  | The context's app's translator, or `undefined`                                                      |
