# @ember-joinery/chart

Charts in shadcn/ui's look: declarative Glimmer SVG on d3-scale and d3-shape, with an API shaped like recharts. An opt-in add-on; its harnesses are in `@ember-joinery/chart/test-support`.

```bash
pnpm add @ember-joinery/chart @ember-joinery/ember
```

The [Chart](/components/chart.md) page and the [Charts](/charts/index.md) gallery show it in use.
