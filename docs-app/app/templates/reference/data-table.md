# @ember-joinery/data-table

What shadcn/ui's Data Table guide builds with, in Ember: `createTable()` on TanStack Table's framework-agnostic core, `FlexRender` and `DataTable`. An opt-in add-on; its harness is in `@ember-joinery/data-table/test-support`. Its `table-core` module re-exports TanStack Table's own API.

```bash
pnpm add @ember-joinery/data-table @ember-joinery/ember
```

The [Data Table](/components/data-table.md) page shows it in use.
