# @ember-joinery/ember

The styled components: every shadcn/ui component, as a Glimmer component with its parts, arguments and part modifiers, plus `<Icon>`. Its CSS (`tokens.css`, `joinery.css`, the other styles and the base colours) is on [Theming](/getting-started/theming.md).

```bash
pnpm add @ember-joinery/ember
```

Each component's own page, under [Components](/components/index.md), shows it in use.
