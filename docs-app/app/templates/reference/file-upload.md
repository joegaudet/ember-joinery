# @ember-joinery/file-upload

File uploads in shadcn/ui's look, on ember-file-upload: a drop zone, a file list and an upload queue. An opt-in add-on; its harness is in `@ember-joinery/file-upload/test-support`.

```bash
pnpm add @ember-joinery/file-upload @ember-joinery/ember tracked-built-ins
```

The [File Upload](/components/file-upload.md) page shows it in use.
