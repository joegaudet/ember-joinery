# @ember-joinery/formwright

Joinery for [Formwright](https://joegaudet.com/ember-formwright/): Joinery's inputs as Formwright controls, a field layout with shadcn/ui's Field anatomy, and harnesses built on Formwright's own, in `@ember-joinery/formwright/test-support`.

```bash
pnpm add @ember-joinery/formwright @ember-joinery/ember @ember-formwright/ember
```

The [Formwright](/formwright/index.md) section shows it in use.
