# API reference

Every package's API, generated from its type declarations when the guide is built: each
module, what it exports, and for each export its arguments, blocks and element (a component),
its parameters (a function or modifier), its members (a class or interface) and its doc comment.
The component pages show the same things in use; this is where to look up a type.

| Package                                                         | What it holds                                                          |
| --------------------------------------------------------------- | ---------------------------------------------------------------------- |
| [`@ember-joinery/ember`](/reference/ember.md)                   | The styled components and `<Icon>`                                     |
| [`@ember-joinery/primitives`](/reference/primitives.md)         | Headless behaviour and utilities                                       |
| [`@ember-joinery/test-support`](/reference/test-support.md)     | A harness for every primitive and component, and the testing helpers   |
| [`@ember-joinery/chart`](/reference/chart.md)                   | Charts: Glimmer SVG on d3 (an opt-in add-on)                           |
| [`@ember-joinery/carousel`](/reference/carousel.md)             | Carousel, on Embla (an opt-in add-on)                                  |
| [`@ember-joinery/data-table`](/reference/data-table.md)         | Data tables, on TanStack Table's core (an opt-in add-on)               |
| [`@ember-joinery/code-block`](/reference/code-block.md)         | Code blocks, highlighted by Shiki (an opt-in add-on)                   |
| [`@ember-joinery/file-upload`](/reference/file-upload.md)       | File uploads, on ember-file-upload (an opt-in add-on)                  |
| [`@ember-joinery/tiptap`](/reference/tiptap.md)                 | A rich-text editor, on Tiptap (an opt-in add-on)                       |
| [`@ember-joinery/power-calendar`](/reference/power-calendar.md) | Calendars and date pickers, on ember-power-calendar (an opt-in add-on) |
| [`@ember-joinery/maskito`](/reference/maskito.md)               | Masked and phone inputs, on Maskito (an opt-in add-on)                 |
| [`@ember-joinery/formwright`](/reference/formwright.md)         | Joinery's inputs as Formwright controls, and their harnesses           |
