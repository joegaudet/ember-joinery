# @ember-joinery/maskito

Masked inputs in shadcn/ui's look, on Maskito: a masked Input with presets, and a phone input that stores E.164. An opt-in add-on; its harnesses are in `@ember-joinery/maskito/test-support`.

```bash
pnpm add @ember-joinery/maskito @ember-joinery/ember
```

The [Masked Input](/components/masked-input.md) and [Phone Input](/components/phone-input.md) pages show it in use.
