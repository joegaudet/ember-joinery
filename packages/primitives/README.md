# @ember-joinery/primitives

Headless, accessible behaviour for Ember: the unstyled layer under
[Joinery](https://joegaudet.com/ember-joinery/). It covers everything
[ember-primitives](https://github.com/universal-ember/ember-primitives) offers, plus the Radix
parts shadcn/ui needs, with one subpath export per feature.

> **Pre-release.** Nothing is published yet; see the
> [repository](https://github.com/joegaudet/ember-joinery#readme).

```bash
npm install @ember-joinery/primitives
```

Full documentation: the guide at **https://joegaudet.com/ember-joinery/guide/**.
